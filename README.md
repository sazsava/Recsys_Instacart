## Назначение
В данной работе была реализована рекоммендательная система для интернет-гипермаркета Instacart. 
Задача состояла в том, чтобы с определенным уровнем точности вывести n-товаров для конкретного покупателя, которые он с наибольшей вероятностью купит в следующей транзакции. 
Для удобства также был написан ряд классов, позволяющих делать следующее:
*По идентификатору пользователя выдавать набор из N наиболее релевантных для него товаров.
*По массиву идентификаторов пользователей выдавать массив наборов из N наиболее релевантных для них товаров.
*Добавить свежие данные о транзакциях.
*Обновить/добавить данные о характеристиках товаров.
*Обучить рекомендательную систему заново.

## Инструкции по работе
 1. Скачайте  **rec_main.py** и папку с предобученными моделями (**'models'**). Для удобства сохраните их в одну папку.
 2. В эту же папку поместите данные по продуктам и транзакциям отсюда [Данные для обучения модели](https://www.kaggle.com/competitions/skillbox-recommender-system/data).
 Можете сделать это вручную или использовать библиотеку kaggle. Тогда для сохранения файлов в папку необходимо запустить следующий блок кода:
```import kaggle
   !kaggle competitions download -c skillbox-recommender-system
   !unzip skillbox-recommender-system.zip
```
Учтите, что для его использования нужно быть зарегестрированным на платформе Kaggle, а также выполнить ряд действий для настройки пользования одноименной библиотекой. 
[Инструкция как это сделать в jupyter notebook(на английском языке)](https://saturncloud.io/blog/how-to-import-kaggle-datasets-into-jupyter-notebook/)
 3. Проверьте пути до указанных файлов в rec_main.py (смотрите сразу под блоком кода с импортом библиотек), поменяйте их на нужные.
 4. Запустите скрипт **rec_main.py** через командную строку cmd, powershell командой `python main.py` или любым другим излюбленным способом.
Для запуска с исходным набором параметров (не меняя исходные данные, n = 10) для получения предсказания достаточно внести user_id или несколько user_id.
	В скрипте прописано два возможных способа передачи в модель аргументов:
        А) через командную строку при запуске скрипта
        Б) если в командной строке не прописаны аргументы запуска, будет предложено ввести эти аргументы последовательно, нажимая Enter после каждого ввода.
 5. На экране появится массив из id товаров по заданным user_id

## Чуть подробнее по способам передачи аргументов в модель:
###МЕТОД А (Напрямую в командной строке)

Чтобы запустить модель таким способом необходимо передать аргументы в строке запуска скрипта main_rec.py
Опции для передачи:
  -h, --help            покажет все возможные аргументные опции и остановит запуск скрипта
  -user_ids USER_IDS [USER_IDS ...], -ui USER_IDS [USER_IDS ...]
                        User id (одно число int) или массив user ids (несколько int через пробел) ОБЯЗАТЕЛЬНЫХ для предсказания
  --n N, -n N           N-продуктов (число int) которые будут выведены на экран в результате предсказния. Необязательный аргумент. По умолчанию равно 10.
  --new_products NEW_PRODUCTS, -p NEW_PRODUCTS
                        Новые данные по продуктам - Dataframe или путь до него в формате csv (стандартный разделитель).  Необязательный аргумент. По умолчанию None.
  --new_transactions NEW_TRANSACTIONS, -t NEW_TRANSACTIONS
                        Новые данные по транзакциям - Dataframe или путь до него(стандартный разделитель).  Необязательный аргумент. По умолчанию None.
  --refit REFIT, -r REFIT
                        Для переобучения модели (обучения заново на новых данных) необходимо передать флажок 'True' в refit. Необязательный аргумент. По умолчанию False.

Пример запуска со всеми аргументами:
python rec_main.py -ui 2 13 50 1712 -n 8 -p ./data/new_prod.csv -t ./data/new_transact.csv -r True
Для запуска с исходным набором параметром достаточно такого:
python rec_main.py -ui 2 13 50 1712
Для одного пользователя:
python rec_main.py -ui 2

###МЕТОД Б (Подача в виде последовательного ввода)
1. Запустите скрипт как "python rec_main.py".
2. Автоматически будет предложено ввести ряд аргументов, каждое из которых будет предложено после нажатия кнопки Enter.
3. Для начала Вас попросят уточнить user_id для предсказания. Введите их в формате одного числа или нескольких чисел, разделенных пробелом (пример:'2 123 78979').
4. Затем будет предложено поменять количество n в предсказании. Нужно ввести желаемое число или оставить поле пустым (останется значение по умолчанию).
5-6. Далее при необходимости можно будет добавить/обновить данные по продуктам и транзакциям. 
Здесь потребуется ввести Dataframe или путь до него (например, ./data/new_prod.csv) или оставить поле пустым.
7. Наконец, по необходимости можно переобучить имеющуюся модель на новых данных. Для этого необходимо ввести любое значение в поле, в противном случае оставте его пустым.

##Дополнительные аргументы/параметры
Можно при желании предусмотреть подачу в скрипт дополнительного набора параметров (поменять, например, модель или исходные данные, на которых она обучается, параметры обучения и т.д.). 
Такая возможность была предусмотрена  при написании классов, реализованных в скрипте. С уже написанным списком параметров можно ознакомиться в rec_main.py. 
Подробнее про них можно прочитать в рабочих ноутбуках (см. working_process).

##Особенности запуска
Учитывайте, что для запуска скрипта требуются правильные пути до моделей и файлов данных. Эти пути прописаны в самом начале 'rec_main.py', 
чтобы их можно было легко поменять при необходимости. 
Также стоит обратить внимание на то, что релизованные в скрипте модели предполагают определенный набор специальным образом обработанных данных, 
поэтому в случае полной замены исходных датафреймов, добавления, удаления столбцов и т.д., потребуется переобучить модель с нуля (передать в скрипт новые дынные и 
поменять флажок True в аргументе refit).
Список используемых мною версий библиотек можно найти в текстовом документе prerequisites.
